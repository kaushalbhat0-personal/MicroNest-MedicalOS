# A1 Android PoC (experimental)

Isolated from `apps/web`. Not a production app.

## Target stack

- Capacitor 6 + React + Vite SPA (bundled assets — **not** Next.js SSR WebView)
- `@capacitor/preferences` / custom plugin for Keystore-backed key
- SQLCipher (or sqlcipher-android) for encrypted patient DB
- Network status via `@capacitor/network`

## Runtime status on this workstation

See `evidence/a1_environment.json` (generated by env probe).

Android SDK may be present without:

- JDK / `javac`
- Android emulator or USB device
- Capacitor CLI project fully built

**Acceptance:** A1 cannot PASS without runtime proof of encrypted DB + Android Keystore. If those cannot run here, verdict is FAIL or NOT TESTED for Keystore — not CONDITIONAL PASS.
