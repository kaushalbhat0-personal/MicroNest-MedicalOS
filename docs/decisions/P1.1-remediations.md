# P1.1 Remediation Notes (audit gate, no scope change)

Date: 2026-11-02 · Status: applied · P2 NOT started.

## Fixed (P1 severity)

- **R1 CORS**: the browser web app could not call the API cross-origin.
  `ALLOWED_ORIGINS` (explicit list, no wildcards) + `CORSMiddleware`
  (credentials, allow-listed methods/headers). Empty list = same-origin only.
  Covered by `tests/api/test_cors.py`. `.env.example` documents the dev value.
- **R2 Anonymous-endpoint rate limits**: `POST /password-reset/request` and
  `POST /invites/accept` were unthrottled. Both now use the shared limiter;
  throttled responses are indistinguishable from normal ones (no oracle).
- **R3 Seed drift**: migration `0002` seed bundles could silently diverge from
  `platform/authz/permissions.py`. `tests/service/test_seed_drift.py` fails CI
  on any divergence (source of truth = catalog; migration = frozen copy).

## Source-of-truth consolidations (safe, applied)

- Tenant-match 404 helper centralized in `api/v1/_shared.py` (`match_tenant`).
- Session cookie issuance centralized (`set_session_cookies`,
  `issue_session_pair`); refresh uses the same cookie writer.
- `MIN_PASSWORD_LENGTH` centralized in `platform/security/passwords.py`;
  schemas import it.
- Web palette: `apps/web` imports `@healthcare-os/ui` tokens via npm
  workspaces (root `package.json`); `globals.css` only aliases. `Button`
  adoption deferred to P5.

## Findings deferred to P2 (NOT fixed here)

- Security headers middleware (HSTS, X-Content-Type-Options, frame-ancestors).
- `update_membership` last-admin guard has a TOCTOU race (SELECT then UPDATE);
  use `SELECT … FOR UPDATE` in P2 when membership writes multiply.
- Missing single-column FK indexes: `locations.tenant_id`,
  `memberships.role_id`, `invitations.{tenant,role,invited_by}`,
  `verifications.{practitioner,reviewer}`, `membership_locations.location_id`.
  Add in migration 0007 (P2).
- Worker `build_handlers` typing (`# type: ignore[no-untyped-def]` ×2).
- Frontend a11y: no skip-link, errors not `aria-describedby`-linked, no focus
  management (P5 design-system scope).
- `audit.reason` free text could one day carry PHI from a careless caller;
  add a reason allow-list test with the first clinical writer (P3).
